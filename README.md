# Akmal B — Cybersecurity Portfolio

A personal cybersecurity portfolio website for **Akmal B**, a Computer Science Engineering student specializing in Cyber Security at **SRM Trichy**, with an expected graduation year of **2030**.

🌐 **Live Portfolio:** https://akmal-cybersecurity.github.io/Akmal-Portfolio/

---

## 🌟 Features

- **Interactive Particle Background** — A dynamic cursor-reactive particle environment.
- **Modern Portfolio Design** — Clean cybersecurity-inspired interface with glassmorphism and responsive layouts.
- **Dark & Light Mode** — Switch between dark and light themes with persistent preferences.
- **Interactive UI** — Smooth hover effects, card interactions, and subtle visual animations.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Accessibility Support** — Semantic HTML, ARIA support, and reduced-motion preferences.
- **Centralized Portfolio Data** — Personal information, skills, projects, certifications, and achievements are organized through a structured data layer.
